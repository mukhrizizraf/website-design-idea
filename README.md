## Where to push updates

The working copy lives in `I:\My Drive\AI LEARNING\ai-learning-dashboard`. Publishing means copying the changed files into this repo's `ai-learning-dashboard/` folder, running `npm test` there, and pushing to `main`. See [ai-learning-dashboard/CLAUDE.md](ai-learning-dashboard/CLAUDE.md) for the details an AI coding assistant needs.

## Adding a project

1. Make a new folder at the top level, such as `my-project/`, with its own `index.html`.
2. Add a row to the table above.
3. Copy one `<li>` in the root `index.html` and point it at the new folder and a picture.

Keep each project self-contained, with nothing shared between folders, so one can change or be removed without touching the others.

## Before you add anything

This repository is public. Leave out private data, and third-party videos or images you do not have the rights to share.
