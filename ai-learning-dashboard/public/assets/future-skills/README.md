# Future skill icons

20 spare 3D-style illustrations for future skills.

- PNG: 512 x 512, transparent, suitable for uploads.
- WebP: 256 x 256, transparent, optimised for the app.
- index.html: catalogue and individual download links.
- manifest.json: suggested topics, categories, filenames and hashes.
- prompts.json: the built-in image generation prompts.

Use the filenames in the manifest when assigning an image to a future skill. These are spare assets; assigning one to a skill does not create its lesson content. The current dashboard image mapping lives in public/skill-images.js.
