What is a skill?

A skill is a small folder of instructions (a SKILL.md file, sometimes with helper files). When Claude sees that your request matches a skill, it reads those instructions and follows them. It's like giving Claude a recipe card for one job.

In Claude Code

Put the skill folder in ~/.claude/skills/. Then ask in normal words, or type / and the skill name, like /humanizer.

In the Claude app

Word, PowerPoint, Excel and PDF skills are already built in. For other skills, zip the skill folder and upload it under Settings → Capabilities → Skills.

Not using Claude? Copy the “Try saying” example from any card. The skill itself works best in Claude, but the idea still helps in other chatbots.
