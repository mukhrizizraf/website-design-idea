What is a skill?

A skill is a small folder of instructions, usually one file called SKILL.md. When your request matches a skill, Claude reads it and follows it. Think of it as a recipe card for one job.

In Claude Code

Skills live in the folder ~/.claude/skills/. Each skill on this shelf has an install sentence you can paste straight into Claude Code, so it copies the folder for you.

In the Claude app

Word, PowerPoint, Excel and PDF skills are already built in. For other skills, download the ZIP from the skill's page here, then upload the skill folder under Settings, Capabilities, Skills.

Not using Claude? The example words on each skill still help in other chatbots. The skill itself works best in Claude.
