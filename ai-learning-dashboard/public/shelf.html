Skill tu apa?

A skill is a small folder of instructions, usually just one file called SKILL.md. When you ask something that matches, Claude will read it and follow. Like a recipe card for one job lah.

In Claude Code

Skills stay in the folder ~/.claude/skills/. Every skill here got one install sentence, just paste into Claude Code and it will copy the folder for you. Steady.

In the Claude app

Word, PowerPoint, Excel and PDF skills already inside. For the others, download the ZIP from the skill's page here, then upload the folder under Settings, Capabilities, Skills. Done.

Not using Claude? No problem, the example words still can use in other chatbots. But the skill itself best in Claude lah.
