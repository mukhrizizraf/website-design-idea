So what's a skill?

A skill is a small folder of instructions, usually just one file called SKILL.md. When you ask for something that matches, Claude reads it and follows along. Think of it as a recipe card for one job.

In Claude Code

Skills stay in the folder ~/.claude/skills/. Every skill here has an install sentence. Just paste it into Claude Code and it copies the folder for you.

In the Claude app

Word, PowerPoint, Excel and PDF skills are already in there. For the others, download the ZIP from the skill's page here, then upload the folder under Settings, Capabilities, Skills. Done.

Not using Claude? No problem, the example words still work in other chatbots. The skill itself works best in Claude, though.
