# Focused library app

The owner selected a focused library with a sidebar, compact search and colourful cards, then requested removal of the explanatory homepage panels and an app-worthy experience for possible future App Store distribution.

The library becomes the local entry point. The owner's subsequent correction rejects the restrained sidebar direction: preserve the original colourful glass, cartoon book jackets, animated 3D category toys, playful background and spring feedback. App-like means less writing and clearer controls, not a subdued visual identity. Use a floating category rail on desktop, an animated icon strip on phones and a glass Library/Saved/Guide dock. Keep the collection, setup instructions, share links and skill sheets. Remove the oversized library hero and three unwanted explanatory homepage chapters.

Spread the homepage books across distinct viewport positions instead of a central stack. Desktop books surround a small launcher; phones use three columns above the launcher and category dock. Give the books independent float and tilt motion, respect reduced motion, and keep their covers within the usable viewport.

Saved skills live on this device, without accounts. Search, difficulty and category filters combine; preferences survive reload. Add a web app manifest and a versioned, same-origin offline shell. This prepares an installable web app; native packaging and store submission are outside this local UI change.

Approaches considered: polishing the promotional homepage would retain the extra step before the useful library; a native rewrite would duplicate working functionality and change the platform. The selected library shell uses the existing dependency-free HTML, CSS and JavaScript.

Verify desktop, short laptop and phone layouts, keyboard controls, empty results, saved items, storage failures, deep links, install assets and offline loading. Keep the published repository untouched unless publication is requested.
